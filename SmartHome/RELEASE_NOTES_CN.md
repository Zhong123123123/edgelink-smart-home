# SmartHome 发布说明（中文）

## 版本信息

- 版本：`v0.4.4`
- 日期：`2026-04-23`
- 平台基线：`STM32F103 + FreeRTOS + ESP8266 + MQTT`

## 版本概览

本项目已从课程 Demo 升级为可用于求职展示的智能家居终端，具备：

1. 统一状态管理
2. 传感器采集任务框架
3. 显示任务框架（串口模拟）
4. MQTT JSON 协议（兼容旧命令）
5. 告警任务与自动/手动双模式
6. 集中配置与分级日志
7. MQTT 断线重连（退避 + WiFi 周期重初始化）
8. 重连失败计数上报
9. 日志降噪与串口可读性优化
10. 运行时日志级别可调

## v0.4.4 重点

1. 新增运行时日志级别接口：
   - `Log_SetLevel(...)`
   - `Log_GetLevel()`
   - `Log_LevelToString(...)`
2. 日志宏从编译期裁剪改为运行时过滤。
3. MQTT 新增 `set_log_level` 命令：
   - 支持数字等级（`0/1/2`）
   - 支持字符串等级（`error/warn/info`）
4. 状态上报增加 `log_level` 字段。
5. 主函数启动时输出当前日志级别。

## v0.4.3 重点

1. MQTT 下行日志改为摘要模式：
   - JSON 命令记录 `topic + cmd`
   - 旧命令记录 `topic + legacy_cmd`
   - 其他报文记录 `topic + payload 长度`
2. 解析失败日志截断 payload，减少串口刷屏。

## v0.4.2 重点

1. 传感器日志降噪：
   - 保留状态变化日志（恢复/失效）
   - 保留低频心跳采样日志
2. 显示刷新降频：
   - 关键状态变化才刷新
   - 周期心跳兜底刷新
3. 串口显示可读性优化：
   - 紧凑固定格式
   - 状态短标签（`AUTO/MAN`、`UP/DN`、`OK/BAD`）

## 累积能力

1. 统一状态结构 `SmartHomeState`
2. `SensorTask` / `DisplayTask` / `AlarmTask`
3. MQTT JSON 上下行与旧协议兼容
4. 阈值告警与模式切换
5. 分级日志与集中配置
6. 重连失败计数 `mqtt_reconnect_fail_count`
7. 运行时日志级别调节

## 当前任务集合

在 `1_App/main.c` 中注册：

1. `MqttTask`（优先级 10）
2. `AlarmTask`（优先级 4）
3. `SensorTask`（优先级 3）
4. `DisplayTask`（优先级 2）
5. `KeyTask`（优先级 2）
6. `LedTask`（优先级 1）

## 已知限制

1. 传感器和显示驱动仍为 stub/串口模拟版本。
2. 告警历史尚未落盘存储。
3. 重连策略可用，但仍有进一步优化空间。

## 下一步计划

1. 对接真实 DHT11/DHT22 驱动。
2. 增加蜂鸣器真实设备链路并接入告警动作。
3. 增加低频诊断上报用于长期稳定性观测。
